Tilt guide

In Rive: bind a View Model to the artboard as its default instance. Any Number or Integer property in it gets a Tilt switch here under Data binding.

Axis — beta: tilt forward/back. gamma: tilt left/right. alpha: compass turn (rarely useful).

Calibrate — turn Tilt on, tilt through your real range while watching the live value, then set "sensor min/max" to match what you saw. Set "output min/max" to the value range your design needs.

Starting points — stand-mounted, tilt toward/away: axis beta, sensor 60 to 120. Held flat, tilt side to side: axis gamma, sensor -45 to 45. Held upright like a phone: axis gamma, sensor -30 to 30.
